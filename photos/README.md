# Foto's toevoegen

Elke maand als je een nieuwe foto van de boom maakt:

1. Zet de foto in deze map, bijvoorbeeld `2026-09.jpg` (formaat: `JAAR-MAAND.jpg`).
2. Open `photos.json` in de hoofdmap van het project en voeg een regel toe:

```json
{ "date": "2026-09", "file": "2026-09.jpg", "caption": "Nog volop groen blad" }
```

3. Commit en push de wijziging naar GitHub — de website update automatisch.
