# TreeTime 🌳

Schoolproject: elke maand een foto van dezelfde boom, vanaf dezelfde plek, om te zien hoe hij verandert door de seizoenen.

## Live site

Zodra GitHub Pages actief is, staat de site op:
`https://<jouw-gebruikersnaam>.github.io/TreeTime/`

## Een foto toevoegen

Zie [`photos/README.md`](photos/README.md) voor de stappen.

## Lokaal bekijken

Open gewoon `index.html` in je browser, of start een lokale server:

```
python -m http.server
```
